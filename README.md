# 手写数字识别基础实验（PyTorch）

依据 `docs/task5.md` 完成 MNIST 数据准备、多层感知器定义、训练与测试、模型保存、曲线绘制和单张图片预测。全部使用 PyTorch，无 PaddlePaddle 依赖。主要函数与数据形状附有中文说明。

## 环境与运行

在项目根目录执行，沿用现有 `.venv`（Python 3.8.10）。依赖固定为 PyTorch 2.4.1 CPU、torchvision 0.19.1 CPU、NumPy 1.24.4、Matplotlib 3.7.5 和 Pillow 10.4.0。

```bash
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
python main.py --predict output/sample_digit.png
```

首次运行从 torchvision 的 MNIST 数据源下载数据，保存在 `data/MNIST/raw/`；后续读取本地数据。完整训练会覆盖 `output/` 下的同名产物。需要保留已有结果时指定其他目录：

```bash
python main.py --output-dir output/new_run
python main.py --predict output/new_run/sample_digit.png --output-dir output/new_run
```

识别自己的图片：

```bash
python main.py --predict path/to/digit.png
# 白底黑字时反转为训练数据的黑底白字方向。
python main.py --predict path/to/digit.png --invert
```

输入应是裁剪、居中、留有适当边缘的单个数字。预处理仅做灰度化、缩放到 28×28 和归一化，不包含照片去噪、数字检测或自动居中。

所有操作统一从根目录 `main.py` 启动。直接运行或在编辑器运行 `main.py`，会依次完成数据准备、训练、评估、保存模型、训练曲线绘制和预测图生成。`src/` 内文件作为包模块使用，不再作为独立脚本启动。参数说明使用 `python main.py --help` 查看，预测时也可通过 `--model` 指定其他权重文件。

已有训练结果时，可以单独重绘，不重新训练：

```bash
python main.py --plot-only
```

重绘需要输出目录中已有的 `epoch_history.csv`、`best_model.pt`，以及本地 MNIST 测试集；它会更新训练曲线、预测图和示例图片，不修改模型权重或训练指标。

## 实验设计与代码对应

| 步骤 | 实现 | 内容 |
| --- | --- | --- |
| 统一入口 | `main.py` | 集中解析参数，调用完整实验、单独绘图或单图预测 |
| 数据准备 | `src/data.py` | MNIST 官方 60,000 张训练图、10,000 张测试图；像素按 `x / 255 * 2 - 1` 归一化到 [-1, 1] |
| 网络定义 | `src/model.py` | 展平 28×28 输入，依次通过 100、100、10 个神经元；两个隐藏层使用 ReLU |
| 训练与评估 | `src/train.py` | 30 轮、批次 128、Adam 初始学习率 0.005；每 4,000 次参数更新乘 0.1；种子 42，CPU 线程数 2 |
| 保存与展示 | `src/train.py` | 保存最优及末轮权重、逐批与逐轮指标、训练曲线、测试集前 16 张预测图 |
| 单图预测 | `src/predict.py` | 独立加载模型，预处理输入，再用 Softmax 得到十类概率 |

`CrossEntropyLoss` 接收网络原始分数，内部包含 LogSoftmax，因此训练前不额外做 Softmax。此处理遵循 [PyTorch 官方交叉熵文档](https://docs.pytorch.org/docs/2.4/generated/torch.nn.CrossEntropyLoss.html)。标签为 `[N]` 的 int64，类别只有 0～9。

训练集在每轮打乱，测试集保持顺序，不丢弃最后一个不足批次。训练损失与准确率统计训练中各批次更新前的预测；测试指标由该轮结束后的固定权重计算。平均损失按样本数加权，准确率为正确样本数除以总样本数。

## 相对原示例的必要调整

| 原示例 | 本实现 |
| --- | --- |
| 旧版 Paddle 动态图、数据读取与权重文件 | 使用 PyTorch `nn.Module`、`DataLoader`、`state_dict`；数据由 [torchvision MNIST](https://docs.pytorch.org/vision/stable/generated/torchvision.datasets.MNIST.html) 读取 |
| 训练数据仅在 512 条缓冲区内打乱 | `DataLoader(shuffle=True)` 在全部训练样本上打乱，保留数据划分和批次大小 |
| 训练前只调用一次 `train()`，测试后未恢复训练模式 | 每轮训练开头调用 `train()`，测试时调用 `eval()` 并禁用梯度；当前网络没有 Dropout/BatchNorm，但明确保持正确流程 |
| 对各测试批次准确率直接取均值 | 按全部 10,000 张的正确总数计算，避免最后 16 张被赋予过大权重 |
| 每批将横轴增加 256，记录首个样本的损失 | 记录真实更新次数、累计样本数和批次平均交叉熵；曲线按轮次绘制 |
| 最优权重要在第 11 轮以后才保存，预测路径另行硬编码 | 从第一轮即可保存最优模型，预测默认加载 `output/best_model.pt` |
| 预测时重复增加维度、标签表包含 10、使用已移除的 `Image.ANTIALIAS` | 单图输入固定为 `[1, 1, 28, 28]`，类别为 0～9，使用 `Image.Resampling.LANCZOS` |

本实验沿用任务书，每轮查看测试结果并按测试准确率选模型，没有独立验证集。因此最优测试准确率属于课程示例的模型选择结果，不能视为独立测试对泛化能力的无偏估计。PyTorch 与原框架的初始化及打乱顺序不同，也不保证重现原示例的数值。

## 输出文件

| 文件 | 含义 |
| --- | --- |
| `output/best_model.pt` | 测试准确率最高的模型参数；同分时保留最早一轮 |
| `output/last_model.pt` | 最后一轮的模型参数 |
| `output/metrics.json` | 参数、版本、样本数、最优轮次、最优及末轮测试结果 |
| `output/epoch_history.csv` | 每轮开始时的学习率、训练/测试平均损失及准确率 |
| `output/batch_history.csv` | 每批的实际更新次数、累计样本数、轮次、平均损失、准确率及本次更新使用的学习率 |
| `output/training_curves.png` | 分别展示训练与测试的损失曲线、准确率曲线 |
| `output/test_predictions.png` | 最优模型对测试集前 16 张的预测与真实标签 |
| `output/sample_digit.png` | 测试集第 0 张原始灰度图，用于独立加载预测 |
| `output/sample_prediction.json` | 上述图片的真实标签、预测与十类概率 |
| `output/train.log` | 本次完整训练的终端输出 |
| `output/verification.json` | 模型重载评估、预处理、学习率边界等验收摘要 |

图像保存为文件，不弹出 GUI 窗口。仅重新预测时无需训练：`python main.py --predict output/sample_digit.png`。调整轮数可使用 `--epochs`，但少于 30 轮不等于完成任务书的完整训练。

## 历史实现与实测结果

使用上述默认参数，在现有 Python 3.8.10 虚拟环境中以 CPU 完成了全部 30 轮训练，共 14,070 次参数更新。第 20 轮最优测试准确率为 **97.65%（9,765 / 10,000）**，测试平均交叉熵为 0.090704；末轮测试准确率为 97.56%。保存后重新加载最优权重，在全部测试集上再次计算，结果一致。导出的测试集第 0 张真实数字为 7，独立预测入口识别为 7。

首次实现时核验了 128+1 个样本的不等长批次统计、4,000/8,000/12,000 次更新后的学习率、单图归一化与白底反转、PNG 文件完整性；`python -m pip check` 无依赖冲突。此前命令行检查未采用编辑器的 `standard` 模式，不能据此说明编辑器没有标红。

统一入口调整后，将 `train.py`、`predict.py` 中依赖脚本搜索路径的导入改为包内相对导入，并添加 `src/__init__.py`。使用项目解释器、Python 3.8、项目根目录解析路径和 `standard` 模式复核，Pyright 1.1.414 实际分析 6 个文件，0 错误、0 警告。语法检查命令为 `python -m compileall -q main.py src`。

此前统一入口调整时，在临时输出目录中，通过 `main.py --epochs 1` 验证完整训练、评估、模型保存和绘图，首轮测试准确率仍为 93.38%，与原 30 轮记录的首轮一致；又删除临时图片后通过 `--plot-only` 重新生成，并验证 `--predict`、非法参数和从其他工作目录启动。原有 30 轮权重和指标未覆盖；当时未重新执行 30 轮训练，也未验证 GUI 弹窗。

## 拓展实验方案（待批准，尚未执行）

以下方案用于解释基础实验的结果并研究影响因素，不预设准确率一定提高。建议先做 A，再做 B；C 可按兴趣追加。各方案使用独立输出目录，保留基础实验结果。

| 方案 | 研究问题与实验设置 | 控制条件与验收产物 | 工作规模 |
| --- | --- | --- | --- |

| B：学习率策略对照 | 比较恒定学习率 0.005 与现有策略（初始 0.005，每 4,000 步乘 0.1），研究收敛速度及验证表现 | 先将原 60,000 张按类别分层划分为 50,000 张训练、10,000 张验证，保存固定索引。每组采用种子 42/43/44，共 6 次 30 轮训练；同种子的两组共用初始化和打乱顺序，仅改变学习率策略。记录曲线、耗时、验证最优轮次和最终测试准确率的均值/标准差 | 6 次训练；新增验证集选择模型的流程 |

A 和 C 使用基础实验中按测试集选出的模型，因此属于对既有结果的描述分析，不是新的独立泛化证明。C 不加入增强训练；若之后希望研究增强能否改善鲁棒性，应另行设计与批准。执行时间需以当前机器实测为准，不将历史训练耗时直接当作工期承诺。
